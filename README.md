## Publish with GitHub Pages

This repository is named `monmouthdigital.github.io`, so GitHub Pages can publish it from the `main` branch.

1. Upload every file and folder from this package to the repository root.
2. Commit the changes to `main`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The website will be available at <https://monmouthdigital.github.io/> after GitHub completes the deployment.
